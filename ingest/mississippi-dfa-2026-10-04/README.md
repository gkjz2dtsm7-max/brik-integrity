# Mississippi DFA contract and bid pull

Pulled 2026-10-04 from the public Department of Finance and Administration search.

1. Contract grid, empty search: 572 rows, then the detail record for each row. Source: https://www.ms.gov/dfa/contract_bid_search/Contract?autoloadGrid=true
2. Bid and public notice grid, empty search: 141 open rows. Source: https://www.ms.gov/dfa/contract_bid_search/bid?autoloadGrid=true
3. Family pages: statewide, cooperative, competitive (the /competitive-contracts path returned 404; the page that answered is https://www.dfa.ms.gov/competitive-contracts_DEF), and the preapproved vendor index.

This is not a USAspending pull. Do not add these rows to grant totals. Purchase orders, expired awards, and local government awards are not in this file. Names inside the preapproved PDF lists were not extracted. The PDFs are linked from the index.

The same file is on the Mississippi opening page that the Roach Roundup green buttons open.
