# Grok Build Workflows

Locked 2026-09-15 for BRIK Creative and BrucknerDemo.com.

Source: https://x.com/grok/status/2093177018611556527

Scripts in `.grok/workflows/*.rhai` become slash commands. Grok fans the work across clean-context agents. Independent skeptics verify every finding before one report lands. Default budget 128. Cap 1024.

## Commands

1. `/workflows` watch live runs
2. `/workflow <name> {args}` launch
3. `/workflow pause <name>` pause. Journal kept
4. `/workflow resume <name>` continue
5. `/workflow stop <name>` stop children. Journal kept
6. `/deep-research <query>` built-in cited research

## Standing rules

1. One named worktree per project or founding case
2. Never edit live main from two agents at once
3. Fence bank IP, investigative case files, and the demo vault from each other
4. Campaign money never sums into grant totals
5. SpaceXAI coding-data retention opt-in stays OFF for investigative, whistleblower, bank, and demo-vault work
6. Skeptics default real=false. real=true needs a locator they opened
7. No double dashes in user-facing copy or field notes

Copy only the `.rhai` files that belong on this tree. Do not mix journalism case files into the vault. Do not mix bank IP into journalism trees.
